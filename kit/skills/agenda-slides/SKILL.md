# 会議アジェンダのスライドを作る

会議メモを、決まった6枠のアジェンダのスライドにする。

## 同梱ファイル

- `templates/agenda.md` … スライドの雛形（表紙＋6枠）。手順3で読む
- `theme.css` … 見た目（白地・16:9）。手順5で使う

## 手順

1. 会議メモを読む。どのファイルか分からなければ聞く。
2. メモの中身を6枠に振り分ける: 目的／決めたいこと／前回の宿題の確認／議題と時間配分／報告／次回。
3. `${CLAUDE_SKILL_DIR}/templates/agenda.md` を読み、同じ形で `out/agenda.md` を書く。
4. 議題の時間を足し、会議の長さと合うかを確かめる。質問の時間など議題でない時間も、表の行に入れて足す。合わなければ最後のページに一言書く。
5. 書き出す（作業フォルダで実行）:
   `npx -y @marp-team/marp-cli@4.5.1 out/agenda.md --theme-set ${CLAUDE_SKILL_DIR}/theme.css -o out/agenda.pdf --no-stdin < /dev/null`
6. できたファイルの場所と、「要確認」と書いた所を一覧で報告する。

## 出力先

- `out/agenda.md`（中身）と `out/agenda.pdf`（配る用）
- PPTX は頼まれた時だけ。`-o out/agenda.pptx` に変える（各ページが画像になり、文字は直せない）

## 守ること

- メモに無い数字・人名・日付を足さない。分からない所は「要確認」と書く
- 会社名・人名はメモの書き方のまま使う（「（架空）」などの注記も消さない）
- 1ページの箇条書きは6行まで。長い文は短く言い換える
- 書き出しが止まったら、`--no-stdin` と `< /dev/null` が付いているか確かめる
