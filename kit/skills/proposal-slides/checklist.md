# 出す前の点検（5項目）

提案スライドを書き終えたら、上から順に確かめる。1つでも外れたら直してから書き出す。

1. **出典**: 数字と事実のすべてに「出典: ヒアリングメモ ◯行目」が付いている。付けられない数字は消すか「要確認」にした
2. **順番**: 7節が 課題の事実 → 対象の利用者 → 提案の価値 → 解決の方式 → 効果 → 実行計画 → リスク の順になっている。解決の方式が先に出ていない
3. **題名だけで通る**: 各ページの見出しと1行目だけを上から読んで、話がつながる
4. **相手の言葉**: お客さんの呼び方（例：職長、所長、日報）を使っている。社内の略語や説明の無い専門用語が無い
5. **出してはいけない物**: 他社の名前、社内の単価や原価、作り話の事例が入っていない。架空の資料から作ったときは、表紙に（架空）が残っている

点検の結果は「1〜5 のどれを直したか」を1行ずつ報告する。
